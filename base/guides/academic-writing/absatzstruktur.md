# Absatzstruktur (MEAL-Prinzip)

## MEAL ist ein Vollständigkeits-Test, keine Satz-Schablone

Jeder Absatz muss vier **Funktionen** erfüllen:

1. **M**ain Point — eine klare Kernaussage (in der Regel früh im Absatz)
2. **E**vidence — Beleg durch Quelle (bzw. Logik/Beispiel bei quellen.workflow "keine")
3. **A**nalysis — eigene Einordnung/Interpretation
4. **L**ink — inhaltliche Verbindung zum nächsten Gedanken

**Wichtig:** Funktionen sind keine Sätze. Ein Satz darf Evidence und Analysis
zugleich tragen („X zeigt Y (Autor, Jahr), was für Z spricht"). Der Link darf
entfallen, wenn der Folgeabsatz mit einem Konzept-Anker anschließt. Wer jeden
Absatz sichtbar in vier gleichförmige Sätze gliedert, erzeugt den „MEAL-Takt" —
ein Struktur-Tell, das der Stil-Linter flaggt (L9) und Prüfer als generiert
erkennen.

## Absatz-Richtwerte

- **Länge:** 60–180 Wörter (3–9 Sätze), Ziel-Mittel 100–130 Wörter
- **Pflicht-Varianz:** aufeinanderfolgende Absätze unterscheiden sich um
  ≥ 20 % in der Wortzahl; keine identische Satzzahl in drei Folge-Absätzen
  (Details und Linter-Schwellen: `satzrhythmus.md`)
- **Pro Seite:** 3–7 Absätze (je nach Absatzlänge)
- **Minimum:** 2 Absätze pro Unterkapitel

## Absatztypen (Richtwerte, bewusst unregelmäßig verteilen)

| Typ | Zweck | Wörter | Zitate |
|-----|-------|---------|--------|
| Definition | Begriff einführen/abgrenzen | 60-120 | 1-2 |
| Argument | These mit Beleg stützen | 90-180 | 1-2 |
| Analyse | Erkenntnisse einordnen/bewerten | 90-160 | 0-1 |
| Vergleich | Perspektiven gegenüberstellen | 100-180 | 2 |
| Überleitung | Gedanken verbinden | 50-100 | 0 |

Der Kapitelplan weist jedem Absatz eine Ziel-Länge zu (kurz/mittel/lang) und
verteilt sie unregelmäßig über das Kapitel — nicht alles „mittel".

## Häufige Fehler

### Zu lange Absätze
Ein Absatz der mehr als einen Hauptgedanken enthält sollte aufgeteilt werden.

### Absätze ohne Kernaussage
Jeder Absatz braucht EINEN klaren Hauptgedanken, in der Regel früh im Absatz.

### Fehlende Analyse
Nicht nur Quellen aneinanderreihen -- eigene Einordnung ist Pflicht.

### Uniformer Takt
```
NEIN: Jeder Absatz exakt 4 Sätze: Behauptung. Beleg. Einordnung. Überleitung.
JA:   Mal trägt ein Satz zwei Funktionen, mal entfaltet die Analyse sich über
      zwei Sätze, mal fehlt der explizite Link.
```

### Redundanz
```
NEIN: Die KI-Technologie ist eine Technologie, die...
JA:   KI-Technologie ermöglicht...
```

### Schwache Verben
```
NEIN: Es gibt viele Unternehmen, die...
JA:   Zahlreiche Unternehmen setzen...

NEIN: Man kann sagen, dass...
JA:   Es zeigt sich, dass...
```

### Übertriebene Nominalisierungen
```
NEIN: Die Durchführung einer Implementierung...
JA:   Die Implementierung...
```
