# Formulierungshilfen

> **Nachrangig zu Voice-Profil und Anti-KI-Regelwerk** (`ai-writing-signs.md`).
> Nichts in diesem Guide ist Pflicht. Diese Wendungen sind Notfall-Gerüst, kein
> Soll-Zustand: Wer sie braucht, nutzt sie **höchstens 1× pro Arbeit** — die
> Wiederholung derselben Wendung ist ein Stil-Fehler (Schablonen-Tell).
> Nichts aus diesem Guide darf auf der Floskel-Blockliste des Stil-Linters stehen
> (`preferences.md → Verbotene Floskeln`); bei Konflikt gilt die Blockliste.

## Konnektoren (aus dem Voice-Profil)

Bevorzugt — sparsam und abwechselnd einsetzen, nie zwei Sätze in Folge mit
Konnektor beginnen:

| Funktion | Bevorzugt | Meiden (Dauer-Füller) |
|---|---|---|
| additiv | zudem, ferner, des Weiteren | darüber hinaus, außerdem (inflationär) |
| schlussfolgernd | folglich, somit, daher, demnach | dabei, hierbei, wobei |
| adversativ | jedoch, allerdings, hingegen | nichtsdestotrotz |

## Einleitung eines Themas

Selbstreferenzen („Die vorliegende Arbeit", „Diese Fallstudie") **max. 2× im
gesamten Werk** (Voice-Profil §5). Varianten:

```
Die vorliegende Arbeit befasst sich mit...
Im Mittelpunkt der Untersuchung steht...
Gegenstand dieser Analyse ist...
Die zentrale Fragestellung lautet...
```

Besser als jede Floskel: direkt mit dem Sachverhalt beginnen
(„Ein mittelständisches Unternehmen steht vor der Entscheidung, ...").

## Quellen einführen (Autor als Subjekt — Voice-Profil-Präferenz)

```
[Autor] (Jahr) argumentiert, dass...
[Autor] (Jahr, S. X) zeigt...
Nach [Autor] (Jahr)...
Wie [Autor] (Jahr, S. X) darlegt...
Einer Studie von [Autor] (Jahr) zufolge...
[Autor] (Jahr) definiert [Begriff] als...
```

Variieren: nicht jede Quelle mit demselben Verb einführen (argumentiert,
zeigt, beschreibt, analysiert, kritisiert, unterscheidet, ...).

## Gegenüberstellung

```
Während [A] argumentiert..., vertritt [B] die Position...
Im Gegensatz zu [A] betont [B]...
[A] und [B] stimmen darin überein, dass...
Anders als [A] sieht [B]...
```

## Kritische Würdigung

```
Diese Argumentation lässt sich kritisch hinterfragen...
Einschränkend ist anzumerken, dass...
Dieser Ansatz weist jedoch Limitationen auf...
Es bleibt offen, inwieweit...
Problematisch erscheint dabei...
```

## Schlussfolgerungen

Nur im echten Fazit-Kapitel, und dort sparsam:

```
Die Analyse hat gezeigt, dass...        (Voice-Profil-Präferenz: rückblickend, ohne Meta-Floskel)
Aus den dargelegten Erkenntnissen ergibt sich...
```

**Gestrichen (KI-Signposting, vom Stil-Linter geblockt):**
~~„Vor diesem Hintergrund zeigt sich..."~~ ·
~~„Es wird deutlich, dass..."~~ ·
~~„Dies führt zu der Erkenntnis, dass..."~~ ·
~~„Zusammenfassend lässt sich festhalten..."~~ (nur 1× im Fazit toleriert) ·
~~„Von besonderer Bedeutung ist..."~~ ·
~~„In diesem Zusammenhang ist festzustellen..."~~

Statt Signpost-Floskel: die Aussage direkt formulieren und belegen.

## Ergebnisse einordnen

```
Diese Ergebnisse deuten darauf hin, dass...
Dies steht im Einklang mit den Erkenntnissen von [Autor] (Jahr)...
Der Befund widerspricht der Annahme von [Autor] (Jahr), dass...
```

## Handlungsempfehlungen

```
Auf Basis der gewonnenen Erkenntnisse empfiehlt sich...
Für die Praxis ergibt sich daraus...
Organisationen sollten daher...
```
